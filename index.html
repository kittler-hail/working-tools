Tutorial Penggunaan

1. Data Sumber

Selalu tampil di atas. Paste history QR Pay dan history bonus di sini — dipakai bersama oleh Cek Bonus dan New Member First Deposit.

2. Cek Bonus

Pilih persentase, klik "Proses Bonus". Satu tabel menampilkan tiga jenis isu: Pending (belum dapat bonus), Tidak Sesuai (nominal beda dari seharusnya, kekurangan akibat pembulatan ke ribuan dianggap aman), Dobel (bonus diberikan lebih dari sekali).

3. New Member First Deposit

Paste daftar id member baru, klik tombolnya. Deposit pertama tiap id dicari dari Data Sumber; belum deposit = Rp0.

4. ID Bermasalah

Tandai id yang perlu diwaspadai beserta kategorinya. Otomatis muncul di hasil Cek Bonus dan New Member First Deposit; daftarnya tersembunyi sampai diklik, dan hapus id butuh 2x konfirmasi.

Daftar ini tersimpan di browser, jadi rawan hilang kalau ganti perangkat/browser. Pakai "Export Backup" untuk simpan ke file, dan "Import Backup" untuk memulihkannya kapan saja.
